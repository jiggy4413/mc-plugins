# Design concepts (not part of the pack)

Brainstorm work kept for reference. Nothing here is loaded by the server or the resource pack.

- `agamemnon/` - black and gold Greek-style "Agamemnon" (Warlord) set with exposed skin, the
  custom helmet, item icons, worn layers and the scripts that drew them (`warlord-preview.png`).
- `helmets-3d/` - 3D helmet concepts and renders (`warlord-3d-preview.png`, `helmets-3d-preview.png`).
  The Valentines/Summer helmets in there were drawn as Nova variants; those sets are being redesigned.
